# Web Development Projects

A collection of front-end web development projects built using vanilla HTML, CSS, and JavaScript — no frameworks, no build tools, just core web technologies.

## Projects

### 1. [Personal Portfolio Website](./Portfolio_App)

A modern, responsive portfolio site with a dark theme, animated typing effect, and a fully working contact form.

![Portfolio Preview](Portfolio_App/images/Screenshot%20From%202026-08-29%2000-51-32.png)

**Highlights:**
- Responsive navigation with mobile hamburger menu
- Animated typing effect cycling through job titles
- About, Skills, Projects, and Contact sections
- Scroll-based active nav highlighting and reveal animations
- Client-side contact form validation

📄 Full details: [`Portfolio_App/README.md`](./Portfolio_App/README.md)

---

### 2. [To-Do List App](./ToDo_App)

A lightweight task manager that persists your to-do list in the browser using `localStorage`.

![To-Do App Preview](Portfolio_App/images/Screenshot%20From%202026-08-29%2000-54-54.png)

**Highlights:**
- Add, complete, and delete tasks
- Custom checkbox and delete icons (inline SVG)
- Data persists across page reloads via `localStorage`
- Simple "render from state" architecture

📄 Full details: [`ToDo_App/README.md`](./ToDo_App/README.md)
